# typoscope

A digital reading window for PDFs: drag and resize a rectangle over the page to 
isolate one line or block of text at a time, with everything outside it dimmed. 

Accessibility aid for thesis reading while I experience visual snow (post-concussion symptom). 

## Usage

```bash
python3 -m http.server
```

Open `http://localhost:8000`, pick a PDF, and use the focus rectangle to
read.
