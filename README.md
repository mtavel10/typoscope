# typoscope

A digital reading window for PDFs (and eventually web articles): drag and
resize a rectangle over the page to isolate one line or block of text at a
time, with everything outside it dimmed. Inspired by a physical typoscope —
a card with a cutout used to keep focus on one line while reading.

## Usage

```bash
python3 -m http.server
```

Open `http://localhost:8000`, pick a PDF, and use the focus rectangle to
read.
